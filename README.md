# AI 图片提示词模板库

这是一个用于收集、整理和复用 AI 图片生成提示词的开源资料库。

## 模板目录

### 1. 社交媒体推广图
用于 Instagram、LinkedIn、Facebook 等平台的推广图片。

### 2. 产品广告图
用于产品展示、卖点宣传和商业广告。

### 3. 活动海报
用于活动宣传、展览、聚会和发布会海报。

### 4. 其他图片模板
待补充原始提示词后整理。

## 使用方法

1. 选择符合需求的提示词模板。
2. 将方括号中的占位内容替换为自己的信息。
3. 告诉 AI 图片用途、目标受众、视觉风格和尺寸。
4. 根据生成结果继续调整提示词。

## 来源与说明

本仓库用于个人学习与提示词整理。模板将逐步补充，并尽量保留原文、中文翻译和使用示例。
