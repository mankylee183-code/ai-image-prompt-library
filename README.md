## 使用方法

1. 打开上方最符合你需求的模板。
2. 复制模板中的提示词，并将方括号中的占位内容替换成自己的信息。
3. 向 AI 说明图片用途、目标受众、视觉风格、配色和画面比例。
4. 如果使用 ChatGPT 图片生成，可直接要求它根据完整提示词生成图片。
5. 检查生成结果，继续调整构图、灯光、文字和细节。

## 提示词使用建议

- **明确目标：** 说清楚图片给谁看、用于什么平台、希望传达什么信息。
- **描述视觉：** 指定风格、配色、构图、背景、光线和主体位置。
- **注意文字：** 图片中的小字和复杂文字可能不准确；重要文案应在生成后检查，必要时用设计工具重新排版。
- **提供参考：** 如果有喜欢的风格或布局参考图，可以一并提供给 AI。
- **迭代优化：** 一次只调整几个重点，方便比较不同版本的效果。

## 记录生成案例

建议为表现好的作品保存以下信息，便于日后复用和改进：

- 案例名称与用途
- 使用的模板类别
- 最终提示词
- 生成图片或图片链接
- 效果评价与下一次优化方向
